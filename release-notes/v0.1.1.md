## WardenBio 0.1.1

Packaging fix only — the app itself is unchanged since 0.1.0.

- The `.dmg` is now signed with Developer ID before it is notarized. The 0.1.0 disk image carried
  a valid notarization ticket but no signature of its own, which Gatekeeper rejects with
  "no usable signature" — opening the downloaded dmg could be blocked. The app inside it was
  correctly signed, notarized and stapled, so an already-installed 0.1.0 is fine.

See the [0.1.0 notes](https://github.com/xVanTuring/WardenBio/releases/tag/v0.1.0) for what
WardenBio does.

## WardenBio 0.1.1

只是打包修复，App 本身相比 0.1.0 没有变化。

- `.dmg` 现在会在公证之前先用 Developer ID 签名。0.1.0 的磁盘映像有合法的公证票据，但自身没有签名，
  Gatekeeper 的评估是「no usable signature」，双击下载来的 dmg 可能被拦。里面的 app 签名、公证、
  staple 都是正常的，已经装好的 0.1.0 不受影响。

功能说明见 [0.1.0 的发布说明](https://github.com/xVanTuring/WardenBio/releases/tag/v0.1.0)。
