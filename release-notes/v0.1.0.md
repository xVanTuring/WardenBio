## WardenBio 0.1.0

First release. Biometric unlock for the Bitwarden browser extension on macOS — without running
the Bitwarden Desktop app.

- A menu-bar app plus an embedded native messaging host (`BioHost`), launched by the browser on demand
- Touch ID (or device password) unlock; the account key is kept in the login keychain
- Manifest install / removal for Chrome, Chromium, Edge, Brave, Vivaldi, Arc and Firefox
- Signed with Developer ID and notarized by Apple

Requires macOS 14 or later. Download the `.dmg`, drag `WardenBio.app` into `/Applications`
(the manifest records an absolute path, so install it again if you move the app), then follow the
"Keys" tab to enter your User ID and encryption key.

## WardenBio 0.1.0

第一个版本。在 macOS 上给 Bitwarden 浏览器扩展做生物识别解锁，不需要运行 Bitwarden 桌面客户端。

- 菜单栏 App + 内嵌的 native messaging host（`BioHost`），由浏览器按需拉起
- Touch ID（或设备密码）解锁，账号密钥存在登录钥匙串里
- 可在 App 内为 Chrome、Chromium、Edge、Brave、Vivaldi、Arc、Firefox 安装或卸载 manifest
- Developer ID 签名并经过 Apple 公证

需要 macOS 14 或更新版本。下载 `.dmg`，把 `WardenBio.app` 拖进 `/Applications`
（manifest 记的是绝对路径，换位置后要重新安装一次），再按「密钥」页的指引录入 User ID 和加密密钥。
